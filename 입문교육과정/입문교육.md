- 서비스경로
```
ax-video-orchestrator.duckdns.org
```
- 서비스기능
```
/jobs
```

#### [Content-Type]
```
application/json
```

#### [Header]
- Name
```
X-API-Key
```
- Value
```
fa25...XXX..지금은 비밀!
```

```json
{
	"prompt":"석양지는 해변가에서 뛰어노는 40대 아빠와 6살 아들",
	"provider":"veo"
}
```

```json
	"job_id":"job_XXXXXXOOOOOO",
	"status":"queued"
}
```
